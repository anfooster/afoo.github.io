# Angela Foo Engineering Portfolio - Light Design Revert

This package restores the earlier **white / sage minimalist portfolio design**. It keeps all four finalized project case studies and their local photos, CAD imagery, and technical information.

## Preview first
Open `index.html` in a browser after unzipping. Project links will open the four case-study pages.

## GitHub Pages upload
1. Back up your existing repository using **Code > Download ZIP**.
2. Unzip this package and open the extracted `Angela_Foo_Portfolio_Light_Design_Revert` folder.
3. In your GitHub repository `anfooster/angelafoo.github.io`, upload **the contents of this folder to the repository root**, where `index.html` is located. Do not upload the ZIP as a single file, and do not upload the enclosing folder as a nested directory.
4. Replace all identically named HTML, CSS, JavaScript, and image files. Commit the changes to your GitHub Pages publishing branch.
5. In **Settings > Pages**, verify publishing points to that root directory/branch. Once deployed, hard-refresh your browser.

An older `Angela_Foo_Engineering_Portfolio/` folder or a previous redesign's `assets/` folder may remain in the repository without affecting these pages. You can remove these folders later if unused, but do not delete the repository, `CNAME` or `.nojekyll` without checking your Pages configuration. The old `geneva.html` page is not linked from this version; delete it separately if you want it gone from the public repository.

## Included
- `index.html` - home page
- `fixture.html`, `injection.html`, `bracket.html`, `racing.html` - four finalized case studies
- `styles.css`, `script.js` - earlier minimalist design and interactions
- Project image, video and PDF files in the same directory

This is a **revert of the visual design**, not a revert of the technical case-study content. No live GitHub files were changed while preparing this ZIP.
